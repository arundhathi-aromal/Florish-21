# Twenty-one

A 21-day habit garden. Every day you do a habit, one petal grows.

## Put it on your phone (GitHub Pages)

1. Create a new GitHub repository (public).
2. Upload everything in this folder to the repository root:
   `index.html`, `manifest.webmanifest`, `sw.js`, and the three `icon-*.png` files.
3. In the repository go to **Settings → Pages**, set **Source** to *Deploy from a branch*,
   choose `main` and `/ (root)`, then save.
4. After a minute your app is live at `https://YOUR-USERNAME.github.io/YOUR-REPO/`.
5. Open that link on your phone:
   - **iPhone (Safari):** Share → Add to Home Screen.
   - **Android (Chrome):** menu → Install app.

## Reminders

- Each habit can have several reminders, at any time, on any days (edit a habit to set them).
- The most reliable reminder is **Add to my phone calendar**. It downloads a calendar file with
  repeating alerts that ring even when the app is closed.
- In-app notifications work while the app is open or running in the background. A static site
  cannot wake a closed app on its own. iPhone also needs the app added to the Home Screen first.

## Your data

Everything is stored on your device. Use **You → Save a backup** now and then.
When you update the app on GitHub, your habits stay.
